# 508 Pizza Restaurant Website

A modern, elegant, and responsive website for **508 Pizza**, an artisan pizzeria located on Taha Hussein Street (Military Accounts Complex) in Benghazi, Libya.

## Features

- **Hero Section**: Warm artisan aesthetic highlighting authentic wood-fired style pizza.
- **Interactive Menu**: Filterable menu categories (Pizzas, Sides & Starters, Beverages, Desserts) with item descriptions and pricing in LYD.
- **About Section**: Highlighting fresh ingredients, slow-fermented artisan dough, and local presence in Benghazi.
- **Location & Hours**: Address, opening hours, and direct phone order buttons.
- **Mobile Responsive**: Fully optimized for mobile phones, tablets, and desktops.

## Running Locally

Open `index.html` in any web browser or serve via static server:

```bash
npx serve 508-pizza
```
